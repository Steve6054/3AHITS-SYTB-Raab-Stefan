## Theorie
### Visual Studio Code
Ein Shell Script ist eine Textdatei deren Inhalt aus Shell befehlen besteht. Im VS Code kann man ganz einfach Shell Scripts schreiben indem man eine Datei erstellt und sie mit der Endung `.sh` versieht. Möchte man ein solches Script dann ausführen muss man aber erst noch das execute-Flag für die Datei setzen:
```bash
chmod +x Script.sh
```

### She bang
Man kann dem Shell Script mit `#!` auch sagen mit was es ausgeführt werden soll. Standardmäßig wird `sh` verwendet. Will man das jetzt auf `bash` ändern macht man das folgendermaßen:
```bash
#!/bin/env bash
```

### Variablen
Man kann in der Shell und in Shell Scripts auch Variablen definieren. WICHTIG: Keine Leerzeichen verwenden! Leerzeichen werden nämlich als Platzhalter zwischen einem Befehl und den Parametern interpretiert!
```bash
FILE_NAME=test.txt
DIR_NAME=mydir
```

### Double und Single Quotes
Wenn man in einer Variablen selbst jetzt ein Leerzeichen drin haben will muss man dafür double oder single quotes verwenden.
- double quotes `""` -> werden nur verwendet um Leerzeichen zu ignorieren
- single quotes `''` -> ignorieren zusätzlich Variablennamen

```bash
# double quotes --> Inhalt mit Leerzeichen
NAME=Stefan
TEXT="\$Hallo $NAME"    #\$ um ein $ im Text anzuzeigen
echo $TEXT              # gibt $Hallo Stefan aus

# single quotes --> ignoriert Variablennamen
TEXT2='Hallo $NAME' 
echo $TEXT2             # gibt dann Hallo $NAME aus
```

### curly Braces {}
Die Curly Braces `{}` werden verwendet um einem Befehl zu sagen was der Filename ist und was nicht:
```bash
FILE=myname
echo "$FILE_001.txt"    # funktioniert nicht
echo "$FILE_002.txt"

echo "${FILE}_001.txt"  # gibt myname_001.txt aus
echo "${FILE}_002.txt"
```

Das Problem ohne die curly Braces wäre, dass das Programm nicht weiß wo der Filename aufhört. Beim ersten `echo` würde das Programm nach einer Variable `$FILE_001` suchen, die wir gar nicht definiert haben.

### Übung (log file names)

Gegeben ist:

```bash
DIR="/var/log/"
```

Erzeuge mit echo folgende Ausgaben unter Verwendung der Variabelen DIR:

   - /var/log/nginx
   - /var/log/apache

---

Hierfür müssen wir die curly braces verwenden:
```bash
echo ${DIR}nginx
echo ${DIR}apache
```
