## Theorie

Jedes shell-Programm liefert beim Beenden einen **exit Status**. Dieser kann mit `$?` aufgerufen werden:
- = 0 -> fehlerfrei
- != 0 -> error

### test

Mit dem `test` Kommando wird das Ergebnis eines Vergleichs in den exit-Status geschrieben. Es ist daher die Grundlage für einfache if-Abfragen in der shell. Leerzeichen sind sehr wichtig!

Syntax:
```bash
$ test 'xyz' = 'xyz'; echo $?
0
```

Es kann stattdessen auch `[]` geschrieben werden:
```bash
$ [ 'xyz' = 'xyz' ]; echo $?
0
# Leerzeichen neben den [ ] !
```

### exit
Man kann den `exit` Befehl verwenden um den exit-Status an einer Stelle im Programm zu setzen:
```bash
exit 0 # Status OK
exit 1 # Error Code
```

### Bedingtes Ausführen
Es kann auch unterschieden werden was ausgeführt wird, je nach exit-Status:
- `&&` => Rechte Seite wird ausgeführt wenn `$? = 0`
- `||` => Rechte Seite wird ausgeführt wenn `$? != 0`

Beispiele:
```bash
# 100 > 99:
$ test 100 -gt 99 && echo "Yes, that's true."
Yes, that's true.
```

```bash
$ test 98 -gt 99 || echo "No, that's false."
No, that's false.
```

Es können auch beide kombiniert werden (wie if/else).

Übersicht von Vergleichsoperatoren:
|                   Operator | Description                                   |
| -------------------------: | :-------------------------------------------- |
|             `!` EXPRESSION | Negate.                                       |
|                `-n` STRING | The length of STRING is greater than zero.    |
|        STRING1 `=` STRING2 | STRING1 is equal to STRING2                   |
|       STRING1 !`=` STRING2 | STRING1 is not equal to STRING2               |
|    INTEGER1 `-eq` INTEGER2 | INTEGER1 is numerically equal to INTEGER2     |
|    INTEGER1 `-gt` INTEGER2 | INTEGER1 is numerically greater than INTEGER2 |
|    INTEGER1 `-lt` INTEGER2 | INTEGER1 is numerically less than INTEGER2    |
|                  `-d` FILE | FILE exists and is a directory.               |
|                  `-e` FILE | FILE exists.                                  |
| EXPRESSION `-a` EXPRESSION | logical and                                   |
| EXPRESSION `-o` EXPRESSION | logical or                                    |

### Übung (Datei zu groß)

Schreibe ein Skript mit einer Datei als Argument, es soll der Text Datei ist zu groß ausgegeben werden wenn die Datei mehr als 100 Bytes hat. Die Dateigröße kann mit ls -l und anschließendes cut ermittelt werden.

V1.1: Wenn die Datei nicht mehr als 100 Bytes hat soll der Text Größe OK ausgegeben werden.

---

Script:
```bash
#!/bin/env bash

[ $(ls -l "$1" | cut -d' ' -f5) -gt 100 ] && echo "Datei ist zu groß" || echo "Groeße OK"
```

### Übung (Dir Creator)

Schreibe ein Skript das den Namen eines Verzeichnisses übergeben bekommt. Das Verzeichnis soll angelegt werden wenn dieses noch nicht existiert. Wenn es das Verzeichnis schon gibt soll eine Warnung und der Inhalt des Verzeichnis angezeigt werden.

---

Script:
```bash
#!/bin/env bash

[ -d "$1" ] && {
    echo "Directory existiert bereits!" 
    ls "$1" 
    } || mkdir "$1"
```

Die `{}` sind dazu da um dem Programm zu sagen, dass es bei `&&` beide Befehle ausführen soll (also `echo` und `ls`)

Test:
```bash

existiert.txt
```

### Übung (Stundenplan)

Schreibe ein Bash Script das für den aktuellen Wochentag eine Kurzform des Stundenplans ausgibt:

```bash
$ ./splan.sh
Es ist Donnerstag
  AM SYTB SYTB frei MEDT MEDT BESP BESP
```

Hinweis: Mit date den aktuellen Wochentag ermitteln.

---

Script:
```bash
#!/bin/env bash

DAY=$(date +%u) #Wert von 1-7 -> 1 = Montag

[ $DAY = 1 ] && echo "Es ist Montag -> GGPw SEW ITP2MG frei INSY"
[ $DAY = 2 ] && echo "Es ist Dienstag -> SYTB ITPM ENG ITSE SYTB"
[ $DAY = 3 ] && echo "Es ist Mittwoch -> DE AM NWT REL ENG frei SYTB GGPw AM"
[ $DAY = 4 ] && echo "Es ist Donnerstag -> PH AM SYTE ITPM BESP frei DE"
[ $DAY = 5 ] && echo "Es ist Freitag -> MEDT ITPA REL ITSE MEDT"
[ $DAY = 6 ] && echo "Es ist Samstag -> frei"
[ $DAY = 7 ] && echo "Es ist Sonntag -> frei"
```
