### while Schleifen

```bash 
counter=1
# while [ $counter -le 10 ]     # counter <= 10
while ((counter<=10))
do
    echo $counter
    ((counter++))
done
```

Bei **while**-Schleifen kann man sowohl das `test`-Kommando (`[]`), als auch doppelte Klammern `(())` für die C-Syntax verwenden.

Allgemein markieren die Schlüsselwörter `do` und `done` Anfang und Ende der Schleife.

---

### for Schleifen

for-Schleifen laufen alle Elemte einer Liste durch.

Einzelne Listenelemente sind in diesem Fall durch white-spaces getrennte Strings.

```bash
data="1 2 3 4 5 6 7"
for d in $data
do
    echo $d
done
```

---

#### Kommandozeilenargumente

Es gibt auch die Variable `$@` welche alle Kommandozeilenargumente als Liste enthält wodurch man diese durchlaufen kann.

```bash
for arg in $@
do
    echo $arg
done
```

---

#### brace expansions {}

Über Braces `{}` kann man Schleifen über bestimmte Bereiche laufen lassen.

```bash
for value in {20..25}
do
    echo $value
done
```

---

#### field seperator

Standardmäßig ist ein white-space als Trennzeichen zwischen Listeneinträgen definiert.

Hat man aber andere Trennzeichen dann kann man das Trennzeichen auch ändern.

Achtung: Das definierte Trennzeichen wird dann auch in nachfolgenden Schleifen angewendet!

```bash
mylist="hallo welt,hello world,guten tag;ni hao"
IFS=",;" # internal field seperator
for el in $mylist
do 
    echo $el
done
```

### Übung (Min)

Schreibe ein bash Skript das den Namen einer Datei als Argument akzeptiert:
```
$ ./min.sh input.txt
```
Die Input Datei enthält positive Zahlen die durch white spaces getrennt sind:
```
42
21 57
68 33 1
1
```
Das Skript soll die kleinste Zahl ermitteln und ausgeben.

Hinweis:

Der größte mögliche Wert in bash scripting ist 64 Bit signed
```
$ ((MAXINT=2**63-1))
$ echo $MAXINT
9223372036854775807
```

---

Skript:
```bash
#!/bin/bash

((min=2**63-1))

input=$(cat $1)

for value in $input
do
    if ((value < min))
    then
        min=$value
    fi
done

echo $min
```

```bash
└─$ ./min.sh input.txt
```


Ausgabe:
