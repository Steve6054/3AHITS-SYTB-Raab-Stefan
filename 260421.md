## Theorie

Es gibt mehrere Möglichkeiten um in bash-Skripts zu rechnen:
- let
- expr
- bash Doppelklammer

### let

Verwendet man `let`, dann wird das Ergebnis einer Variable zugewiesen:
```
let a=5+4
let b=100-$a
```

Leerzeichen können nur verwendet werden wenn man den Ausdruck in Double-Quotes `""` setzt.

### expr

Bei `expr` wird das Ergebnis ausgegeben. Das ist gut anwendbar mit `$(...)` command-substitution.
```
echo $(expr 5 + 4)
```

Das `*` wird dabei allerdings als Wildcard interpretiert. Will man das also verwenden muss man stattdessen `\*` schreiben.

### bash Doppelklammer

Syntax: `$((expr))`.
Hier sind Leerzeichen egal. Außerdem können Variablen die in der Doppelklammer stehen ohne `$` angeschrieben werden.
Wenn das Ergebnis nicht weiterverwendet wird kann man das `$` vor der Doppelklammer auch weglassen:
```
((a=2*a)) 
((a++))
((a=a+4))
```

### Übung (Zeitmessung)

Schreibe 2 Skripts: `time_start.sh` und `time_stop.sh`. Bei Aufruf von `time_stop.sh` wird die Anzahl der Sekunden ausgegeben die seit dem letzten Aufruf von `time_start.sh` vergangen sind. 

- Hinweis 1: verwende `date` um die Anzahl der Sekunden seit 01.01.1970 herauszufinden (die UNIX Zeit bezieht sich immer auf diesen Referenzpunkt). 

- Hinweis 2: Speichere die Zeit in `time_start.sh` in einer, mit `mktemp` erzeugten, temporären Datei.

---

`time_start.sh`:
```bash
#!/bin/env bash

TEMP_FILE=$(mktemp)

date +%s > $TEMP_FILE

echo $TEMP_FILE
```

Problem: Wir brauchen den Pfad für die weitere Verwendung in `time_stop.sh`. Damit man sich den Pfad nicht merken oder kopieren muss speichern wir ihn beim Aufruf einfach in einer Variable:

```bash
TIME_FILE=$(./time_start.sh)
```

`time_stop.sh`:

```bash
#!/bin/env bash

LAST_START=$(cat $1)
TIME_NOW=$(date +%s)

echo $(($TIME_NOW - $LAST_START))

rm $1
```

Aufruf und Ausgabe:
```bash
┌──(kali㉿kali)-[~/260421]
└─$ TIMEFILE=$(./time_start.sh)
                                                                                                                                                                  
┌──(kali㉿kali)-[~/260421]
└─$ ./time_stop.sh "$TIMEFILE" 
12
```
