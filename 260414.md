## Theorie
Bei Command Substitution kann die Ausgabe eines Programms als Variablenwert verwendet werden. Syntax: `$(cmd)`

Beispiel:
```bash
$ echo "Das aktuelle Datum ist $(date)"
$ echo "Heute $(date -I) in einer Woche ist $(date --date='+1 week' -I)"
```

### Berechnungen
Um Berechnungen durchzuführen wird die Syntax `$((EXPR))` verwendet. Sollte man bei der Rechnung eine Variable verwenden wollen, braucht man hierbei kein `$` vorm Variablennamen mehr.

Beispiel:
```bash
VAL1=42
VAL2=$((VAL1 * 10))
```

### Übung (Tage bis zum Ball)

Schreibe ein Shell-Skript das die Anzahl der Tage bis zum HTL Ball ermittelt. Die Ausgabe soll in der folgenden Form sein.

```
Es sind noch 42 Tage bis zum HTL Ball (2027-01-16)
```

Hinweise:

- Verwende das `date` Format für  `seconds since the Epoch (1970-01-01 00:00 UTC)`

---

Script:
```bash
#!/bin/env bash

BALL_DATE="2027-01-16"

BALL_EPOCH=$(date -d "$BALL_DATE" +%s)

TODAY_EPOCH=$(date +%s)

SEC_TILL_BALL=$(( BALL_EPOCH - $TODAY_EPOCH ))

DAYS_TILL_BALL=$((SEC_TILL_BALL / 86400))

echo "Es sind noch $DAYS_TILL_BALL Tage bis zum HTL Ball ($BALL_DATE)"
```

- Mit der Option `-d` können wir den `date` Befehl für ein bestimmtes Datum einsetzen
- `+%s` gibt die Sekunden seit `1970-01-01 00:00 UTC` aus

Ausgabe (Ausgeführt am 14.04.2026):
```bash
┌──(kali㉿kali)-[~/260414]
└─$ ./daysremaining.sh        
Es sind noch 276 Tage bis zum HTL Ball (2027-01-16)
```

```

```

Wähle die Wörter aus dieser [Wortliste](testdata/wortliste1000.txt).

- Hinweis: Das Komando `sed -n 5p datei.txt` gibt die 5te Zeile aus. 
- Erweiterung: Das Skript soll auch die Anzahl der in der Wortliste enthaltenen Wörter ermitteln. D.h. die Konstante 1000 soll im Skript nicht vorkommen.
